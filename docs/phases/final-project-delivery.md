# Final Project Delivery Checklist

## End-to-end demonstration flow
1. Start application
2. Log in with authorized account
3. Import roster
4. Enroll authorized students
5. Create attendance session
6. Upload classroom photo
7. Run full + tiled detection
8. Review detections and proposed matches
9. Correct unknown/ambiguous outcomes
10. Confirm attendance
11. Export report
12. Verify DB, review history, and export agreement

## Final delivery report must include
- Architecture summary
- Repository file map
- Installation commands
- Run commands
- API documentation location
- Actual test results
- Evaluation results (where measured)
- Model licensing status
- Known limitations
- Demo script
- Recommended future enhancements

## Quality gate
Do not represent the system as fully accurate or production-ready without supporting evidence.
