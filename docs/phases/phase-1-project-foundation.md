# Phase 1 — Project Foundation and Development Environment

## Goal
Create a runnable backend foundation and development setup.

## Required outputs
- FastAPI entry point
- Centralized configuration with environment variables
- SQLAlchemy + SQLite initialization
- Health-check endpoint
- Structured logging and exception handling
- Development dependency specification
- `.gitignore` baseline
- Setup and run instructions in README
- Basic tests: app import, health endpoint, DB init, config defaults

## Acceptance criteria
Application starts locally, health endpoint works, database initializes, and baseline automated tests pass.
