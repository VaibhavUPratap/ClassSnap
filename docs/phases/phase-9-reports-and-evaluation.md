# Phase 9 — Attendance Reports and Evaluation Framework

## Goal
Implement export/report reliability and reproducible model evaluation.

## Required outputs
- Confirmed-attendance-only CSV and Excel exports
- Session and student history summaries with confirmation metadata
- Spreadsheet formula-injection safe export handling
- Evaluation dataset schema and metrics implementation
- Config-comparison command for detector/recognition settings
- Reproducible machine-readable evaluation outputs with model/config/dataset/date metadata

## Acceptance criteria
Exports match confirmed DB records, and evaluation metrics are reproducible from labeled data.
